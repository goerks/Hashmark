# Navigation {layout=section}

Nach rechts geht die Story weiter, nach unten geht es ins Detail.

## Tasten

| Taste | Wirkung |
| --- | --- |
| → / ← | weiter / zurück auf der Ebene |
| ↓ / Enter | abtauchen |
| ↑ / Esc | auftauchen, Position wird gemerkt |
| Space / Presenter ▶ | der Linie nach – inklusive aller Details |
| B / F5 | Schwarzbild / Vollbild (Presenter) |
| ? | alle Tasten |
| Ctrl+Shift+O / O | Navigations-Übersicht |
| Home | zum Anfang |

## Deep-Links

Jeder Knoten hat eine URL, z. B. `#architektur/parser/direktiven`.

Querverweise funktionieren auch mit dem Pfad-Ende: [siehe Direktiven](#parser/direktiven).
